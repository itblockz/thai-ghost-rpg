# แผนรวม — ประตูหิมพานต์

## ชื่อ
**ประตูหิมพานต์** · บทที่ ๑ — คืนเดือนดับ
(ชื่อเดิม: ตำราปราบผี → คืนเดือนดับ)

## ขอบเขต
ตำนานไทยทั้งหมด: ผี, สัตว์หิมพานต์, ยักษ์, นาค, ครุฑ, คนธรรพ์, เทวดา, ฤๅษี, เสือสมิง ฯลฯ
วรรณคดีดั้งเดิมใช้ได้ แต่ภาพและถ้อยคำต้องสร้างเอง

## เรื่องย่อ
คืนเดือนดับ ประตูที่กั้นโลกมนุษย์กับป่าหิมพานต์และแดนผีแตกออก อาจารย์ผู้เฝ้าประตูหายไป
**ผู้สืบทอดวิชา** ต้องรวบรวม **บริวาร** จากทุกเผ่าพันธุ์ ตามหาอาจารย์ และปิดประตูให้ได้
- ปม: "อาจารย์เจ้า… อยู่กับ 'ท่าน' แล้ว" — 'ท่าน' อาจเป็นผู้ทำให้ประตูแตก
- โทน: บทแรกน่ากลัว (ผีออกมาก่อน) บทต่อไปผจญภัยกว้างขึ้น

## โครงบท (ร่าง)
| บท | ชื่อ | สถานที่ | ตัวละครหลัก |
|---|---|---|---|
| ๑ | คืนเดือนดับ | ศาลาร้าง ป่า หมู่บ้าน | ผีกองกอย กระสือ |
| ๒ | ลำน้ำมืด | ท่าน้ำ กลางน้ำ วังนาค | ผีพราย ผีโขมด (บริวารตัวที่ 3) นาค |
| ๓ | (ร่าง) | ป่าหิมพานต์ | สัตว์หิมพานต์ |
| ๔ | (ร่าง) | ยอดเขา | ครุฑ |

## ระบบบริวาร (แทนระบบของขลัง)
- บริวาร = ตัวละครฝั่งเรา แต่ละตัวมี ขวัญ และฤทธิ์ 2–3 อย่าง (ใช้ระบบสกิลเดิม)
- วิธีได้บริวาร ต่างกันตามกลุ่ม:
  - ผี → ปราบแล้วสะกดไว้
  - สัตว์หิมพานต์ → ช่วยเหลือ / ชนะการประลองแล้วยอมติดตาม
  - เทวดา → บวงสรวง / ทำความดีตามเรื่อง
  - ยักษ์ อสูร → ทำสัญญา
- ทีม: เริ่ม 1 ตัว → ขยายเป็น 3 ตัว

## ยังไม่ทำ / พักไว้
- ระบบแก้ทาง (ไม่ใช้ธาตุ) — ตัวเลือก: คู่ปรับในตำนาน (ข่ม/ทนทาน), ตัวแทงก์ (ยั่วยุ/กันแทน)
- ซ่อนข้อมูลผีบางส่วน
- บันทึกความคืบหน้า, ติดตั้งเป็นแอป

## ตัดสินใจแล้ว
- ข้อมูลฤทธิ์: **บอกทุกกลไก แต่ให้ค้นพบความแรงเอง** — คำอธิบายเป็นประโยคนิทาน บอกว่าทำอะไร ใส่ใคร ตั้งท่าไหม (ฤทธิ์แรงพิเศษบอกว่า "อย่างแรง"); ตัวเลขความแรงเห็นจากตัวเลขลอยตอนใช้; พักฤทธิ์แสดงแยก; ขวัญ/กำลัง/ของขลังเป็นตัวเลข
- ฤทธิ์ศัตรูที่ยังไม่เคยเห็นเป็น "???" จนกว่าจะเห็นใช้ ปราบได้แล้วเปิดหมด
- อานุภาพฤทธิ์ = ค่าคงที่ + ตัวคูณ × ค่าพื้นฐาน (กำลัง หรือ ขวัญสูงสุด) แล้วแต่ฤทธิ์
- ผู้เล่น: **สั่งบริวารอย่างเดียว** (ไม่มีวิชาของตัวเอง) → ระบบของขลังเอาออก
- มุมมอง: **เห็นทีมบนจอ** (เลิกมุมบุคคลที่ 1)
- แนวจอ: **แนวตั้ง** — ศัตรูแถวบน, บริวารแถวล่าง, ปุ่มฤทธิ์ของตัวที่ถึงตาอยู่ล่างสุด

## ก้าวแรกที่เล็กที่สุด (หลังตัดสินใจ)
1. เปลี่ยนชื่อเกม / ตัวเอก / บทเปิดให้ตรงเรื่องใหม่
2. บริวารตัวแรก 1 ตัว (ผีกองกอย — สะกดหลังปราบ) สู้กับกระสือ
3. ปราบกระสือแล้วสะกดเป็นบริวารตัวที่ 2
4. เอาระบบของขลัง (มีดหมอ ตะกรุด มือถือของ) ออก หรือปรับเป็นวิชาของผู้เล่นถ้าเลือก B
