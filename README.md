# คืนเดือนดับ (Thai Ghost RPG)

เกม RPG ตำนานผีไทย เล่นบนมือถือเป็นหลัก — Phaser 3 + Vite

```
npm install
npm run dev     # เปิดบนมือถือในวง Wi-Fi เดียวกันผ่าน IP ที่แสดง
npm run build
```
