# แผนเนื้อเรื่อง — คืนเดือนดับ

## ชื่อเกม
**คืนเดือนดับ** (เดิม: ตำราปราบผี)

## แนวเรื่อง: ตามหาอาจารย์
คืนเดือนดับ อาจารย์หมอผีหายไปจากศาลาวัดร้าง ทิ้งไว้เพียงบันทึกขาดวิ่น
ศิษย์หมอผีออกตามหา ระหว่างทางต้องปราบผีและเก็บร่องรอยของอาจารย์

- ปมหลัก: อาจารย์หายไปไหน → (อนาคต) ไปสู้ผีใหญ่แล้วถูกขังไว้
- ผีใหญ่: ยังเป็นปริศนา
- โทน: น่ากลัว จริงจัง ภาษาโบราณแต่อ่านง่าย

## ที่มาของของขลัง (ไม่มีกฎตายตัว แต่ละชิ้นมีเหตุผลของตัวเอง)
1. ผีขโมยหรือหวงไว้ → ปราบแล้วได้คืน
2. ชาวบ้านมอบให้เป็นการตอบแทน
3. เจอตามสถานที่ที่อาจารย์ทิ้งไว้

**บันทึกของอาจารย์** = คำใบ้และเนื้อเรื่องที่พบตามทาง ไม่ใช่ที่มาของวิชา

## เดโม (2 ด่าน)
| ฉาก | เนื้อหา | ได้รับ |
|---|---|---|
| เปิดเรื่อง (3 หน้า) | คืนเดือนดับ ศาลาร้าง อาจารย์หายไป | มีดหมอ (ของประจำตัว) |
| ก่อนผีกองกอย (1) | ทางเข้าป่า เสียงกระโดดตุบ ๆ | |
| หลังผีกองกอย (1) | ผีกองกอยขโมยตะกรุดของอาจารย์ไปซ่อน ได้คืน พร้อมบันทึกพับอยู่ในตะกรุด: คำใบ้เรื่องกระสือ | ตะกรุด |
| ก่อนกระสือ (1) | หมู่บ้านเงียบ ชาวบ้านปิดประตู แสงวูบวาบเหนือต้นไม้ | |
| จบเดโม (1–2) | กระสือก่อนสิ้นฤทธิ์: "อาจารย์เจ้า... อยู่กับ'ท่าน'แล้ว" | |

## รูปแบบการนำเสนอ
- ภาพนิ่ง pixel art ครึ่งจอบน ข้อความ 1–2 บรรทัดครึ่งล่าง
- ข้อความขึ้นทีละตัว แตะเพื่อแสดงทั้งหมด / ไปหน้าต่อไป
- ภาพใหม่ที่ต้องวาด: ศาลาว่างเปล่า, บันทึกขาด, หมู่บ้านยามดึก

## ขั้นตอน
1. เขียนบททั้งหมดให้อ่านและแก้ก่อน
2. ทำระบบฉากเล่าเรื่อง (ข้อมูลบทอยู่ในไฟล์ data แยก แก้ได้ไม่ต้องแตะโค้ด)
3. วาดภาพประกอบ 3 ภาพ
4. เปลี่ยนชื่อเกมเป็น คืนเดือนดับ ทุกจุด
5. ปรับข้อความรางวัลจาก "ได้รับของขลัง" ให้เข้ากับเรื่อง
