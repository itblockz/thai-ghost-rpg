# แผนรวม — ประตูหิมพานต์

## ชื่อ
**ประตูหิมพานต์**

## ขอบเขต
ตำนานไทยทั้งหมด: ผี, สัตว์หิมพานต์, ยักษ์, นาค, ครุฑ, คนธรรพ์, เทวดา, ฤๅษี, เสือสมิง ฯลฯ
วรรณคดีดั้งเดิมใช้ได้ แต่ภาพและถ้อยคำต้องสร้างเอง

## เรื่องย่อ
คืนเดือนดับ ประตูที่กั้นโลกมนุษย์กับป่าหิมพานต์และแดนผีแตกออก อาจารย์ผู้เฝ้าประตูหายไป
**ผู้สืบทอดวิชา** ต้องรวบรวม **บริวาร** ตามหาอาจารย์ และปิดประตูให้ได้
- ปม: "อาจารย์เจ้า… อยู่กับ 'ท่าน' แล้ว" — 'ท่าน' อาจเป็นผู้ทำให้ประตูแตก
- โทน: บทแรกน่ากลัว (ผีออกมาก่อน) บทต่อไปผจญภัยกว้างขึ้น

## บรรพ
| บรรพ | ชื่อ | ด่าน | ศัตรู | บริวารที่ได้ |
|---|---|---|---|---|
| ๑ | คืนเดือนดับ | ชายป่า, หมู่บ้าน (บอส) | ผีกองกอย, กระสือ | กุมารทอง (เริ่ม), ผีกองกอย, กระสือ (หลังบอส) |
| ๒ | ลำน้ำมืด | ท่าน้ำ, กลางน้ำ, วังนาค (บอส) | ผีพราย, ผีโขมด, นาค | ผีพราย (หลังท่าน้ำ), ผีโขมด |
| ๓ | ป่าช้าวัดร้าง | ประตูวัด, ลานป่าช้า, ศาลาสวดศพ, โบสถ์ร้าง (บอส) | ผีกระหัง, ผีปอบ, ผีเปรต | ผีกระหัง (หลังประตูวัด), ผีปอบ (หลังศาลาสวดศพ) |
| ๔ | (ร่าง) | ป่าหิมพานต์ | สัตว์หิมพานต์ | |

บอสแต่ละตัวมีกลไกของตัวเอง ไม่ซ้ำกัน:
- กระสือ: ม้วนไส้หนึ่งตาแล้วฟาดไส้ (ต้องกางกันภัยให้ทัน ระหว่างตั้งท่าโดนตีแรงขึ้น)
- นาค: พ่นพิษใส่ทุกตน พิษค้างหลายตา (ต้องรักษา — ไฟอุ่นใจของโขมดถอนพิษ)
- ผีเปรต: ช้ามาก เลือดเยอะ "ดูดอาคม" ผ่านปากรูเข็ม ทำให้ของขลังของบริวารตนหนึ่งไร้ผลจนจบศึก (อย่าพึ่งของชิ้นเดียว)

## ระบบหลัก
- **บริวาร**: มีได้ไม่จำกัด ออกศึกได้ 3 (เลือก ✓ ในหน้าเตรียมศึก, สลับตำแหน่งได้)
- **ค่าพื้นฐาน**: ขวัญ (หัวใจ), กำลัง (กำปั้น), ความเร็ว (ขนนก)
- **เส้นเวลา**: ตัวเร็วได้เล่นก่อนและบ่อยกว่า (เกจใต้ตัว) — เท่ากัน: ฝั่งเราก่อน แล้วซ้ายไปขวา
- **ฤทธิ์**: อานุภาพ = ค่าคงที่ + ตัวคูณ × ค่าพื้นฐาน; ฤทธิ์พื้นไม่มีพัก ฤทธิ์แรงมีพัก; ตาเริ่มที่ฤทธิ์ไม่มีพัก
- **ของขลัง**: 7 ชนิด 3 ระดับ (อัญมณี 1–3 เม็ด) สวมได้ 2 ช่อง (ช่องที่ 2 เปิดในบรรพที่ ๒) ใส่ชนิดซ้ำได้
  - ค่าพื้นฐาน: ตะกรุดโทน (ขวัญ), เขี้ยวเสือ (กำลัง), ขนนกการเวก (ความเร็ว)
  - กลไก: ประคำไม้ (กันภัยตาแรก ๆ), ผ้ายันต์ (กันจมน้ำ/ตาพร่า)
  - สายฟาร์ม: ตะกรุดมหาลาภ (ได้ของเพิ่ม), เบี้ยแก้ (โชค ได้ของดีบ่อยขึ้น)
  - แต่ละด่านมีของที่ออกบ่อย บอกอัตราเป็นตัวเลขในคู่มือ
  - **ปลุกเสก**: เอาของที่ไม่ใช้เสกเข้าชิ้นที่อยากให้แรงขึ้น (ขั้นเสก 0–10, ธรรมดา 1 หายาก 3 วิเศษ 10 แต้ม ชนิดเดียวกันได้สองเท่า) — แก้ทั้งของตันและย่ามล้น
- **ขั้น & บารมี**: ชนะได้บารมี ขั้นละขวัญ +1 กำลัง +1 ทุก 4 ขั้น (เพดาน 30); **ของเซ่น** (ไข่ต้ม น้ำแดง บายศรี) ได้ทุกครั้งที่ชนะ ป้อนให้บริวารได้โดยไม่ต้องสู้
- **ออกล่า**: เล่นซ้ำด่านที่ผ่านแล้ว (ไม่ใช่บอส) = 3 ระลอก (ชุดเดิม → ผสม → มีตัวหัวหน้า) ได้ของทุกระลอก ระลอกหลังได้ของดีบ่อยขึ้น ฟื้นเลือดระหว่างระลอก ถอยพร้อมของได้
  - ทีมเล็ก (1–2 ตน) เจอระลอกเบากว่าและฟื้นเลือดมากกว่า
- **ศึกครั้งแรกตามเรื่อง** บางด่านมีชุดศัตรูพิเศษนำโดยตัวหัวหน้า (เช่น ฝูงผีกระหังที่ประตูวัด)
- **สะดวก**: สู้ซ้ำ, ความเร็ว ×2, สู้เอง (ปุ่มวงทอง — เฉพาะด่านที่ผ่านแล้ว), ถอย

## ตัดสินใจแล้ว
- ข้อมูลฤทธิ์: **บอกทุกกลไก แต่ให้ค้นพบความแรงเอง** — คำอธิบายเป็นประโยคนิทาน ใช้รูป "ยิ่ง…ยิ่ง…"
- ตัวเดียวกันใช้ฤทธิ์ชุดเดียวกันทั้งสองฝั่ง (ชื่อและผลเหมือนกัน ต่างแค่ตัวเลข; ศัตรูอาจใช้ไม่ครบชุด)
- บอสไม่เสียตา (เช่น ไม่จมน้ำ) — การ์ดบอสในหน้าเตรียมศึกบอก "ไม่เสียตา"
- คำบรรยายฤทธิ์เขียนจากมุมผู้ใช้: **ศัตรู** = ฝั่งตรงข้าม, **พวกพ้อง** = ฝั่งตัวเอง (ใช้เหมือนกันทั้งบริวารและผี)
- ฤทธิ์ศัตรูที่ยังไม่เคยเห็นเป็น "?" จนกว่าจะเห็นใช้
- ผู้เล่น: **สั่งบริวารอย่างเดียว**
- จอแนวตั้ง — ศัตรูแถวบน, บริวารแถวล่าง, ปุ่มฤทธิ์ล่างสุด
- ภาพ: pixel art ช่องละ 2pt ทั้งเกม (ตัวละคร 32×32, บอสใหญ่ 48×48, ไอคอน 16×16, ภาพเนื้อเรื่อง 64×64, ฉาก 180×320)
- เน้นภาพแทนคำ; ค่าพื้นฐานเป็นรูป+ตัวเลข; ผลอื่นเป็นประโยค
- ไม่ขายของสุ่มด้วยเงินจริง (ถ้าจะขายวันหลัง ต้องเปิดเผยอัตรา — มีอยู่แล้วในคู่มือ)

## แผนเพิ่มเนื้อหา (เพิ่มจริงทีละอย่าง ให้ผู้เล่นได้รู้จักทีละตน)
หลักคือ **หลากหลาย**: ทุกตัวทุกชิ้นต้องเล่นต่างกัน ไม่ใช่แค่ตัวเลขต่าง

บริวาร (บทบาท — วิธีเล่น):
- [x] ผีปอบ — อึด/ดูดเลือด: ยิ่งตียิ่งฟื้น
- [x] ผีพราย — ปิดงาน: ฉุดจมแรงสองเท่ากับเป้าที่เหลือขวัญไม่ถึงครึ่ง
- [x] กระสือ — ตั้งท่าแล้วระเบิด: ฟาดไส้ (ม้วนหนึ่งตา ระหว่างนั้นโดนตีแรงขึ้น)
- [ ] ผีโพง — ตีหมู่: ไฟติดค้าง (มาเป็นศัตรูก่อน)
- [ ] ผีตายโหง — ทุ่มหมดตัว: เลือดยิ่งน้อยยิ่งแรง
- [ ] กินรี — รักษาทั้งทีม แล้วเร่งความเร็ว (บรรพ ๔)
- [ ] คชสีห์ — กันตัว: ล่อให้ศัตรูตีตัวเอง (บรรพ ๔)

ของขลัง (ตระกูล):
- [ ] กันตัว: เหล็กไหล (โดนเบาลง), ลูกอม (รอดตายครั้งหนึ่ง)
- [ ] ฟื้นตัว: น้ำมนต์ (ฟื้นทุกตา), สีผึ้ง (ตีแล้วดูดเลือด)
- [ ] โจมตี: ผ้าประเจียด (บางครั้งแรงสองเท่า), มีดหมอ (แรงขึ้นกับเป้าติดพิษ/ไฟ)
- [ ] จังหวะ: ไม้เท้าฤๅษี (ฤทธิ์พักเร็วขึ้น), กระดิ่ง (ศัตรูช้าลงตอนเริ่ม)

- [x] ระบบสถานะร่วม: ไอคอนแถวใต้ตัวพร้อมจำนวนตาที่เหลือ (จมน้ำ ตาพร่า พิษ ไฟ ช้า ถูกดูดอาคม); ไฟ = ไหม้ทุกตา รักษาไม่ดับ; ช้า = ความเร็ว 60%
- [ ] โบนัสต่อสถานะ (เช่น มีดหมอแรงขึ้นกับเป้าติดพิษ/ไฟ)
ศัตรู: ทุกด่านใหม่มีกลไกใหม่อย่างน้อยหนึ่งตัว (กันให้พวก แยกร่าง สะท้อนดาเมจ)
